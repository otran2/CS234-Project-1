Project 1 for CSE 234
A full end-to-end RAG pipeline using the RapidfireAI source docs as a corupus as well as an experiment notebook testing different configurations.

The notebook experiment.ipynb contains the final 8 configurations tested before submission, while main.py contains the final end-to-end RAG pipeline used. The file output.json is the result of the final main.py run.

As a note, the metric files of all the experiments can be found in a link to a google drive within the metricResults folder in the file resultsLink.txt, while the logs for all experiments may be found through the a link to the same drive within a text file in the logs folder also called resultsLink.txt, with the nested folders of the metrics and logs folders representing the member responsible for producing them.
